# just-vibe visual identity

Created with the built-in image generation tool, directed using the brandkit skill. No API or CLI fallback was used.

Brand idea: a deliberate path from intention to implementation. Palette: paper #F5F5EE, charcoal #20221E, lime #D7FB52. Typeface: self-hosted Geist, licensed under OFL-1.1. The generated raster mark is the identity source; the board illustrates applications, not product screenshots.

## Primary mark

Use case: logo-brand. Create the primary standalone symbol for "just-vibe", a thoughtful developer toolkit for coding agents. Strategy: creativity guided by repeatable engineering workflows; personality direct, assured, modern, independent. Core metaphor: a continuous path that changes direction with intent. Design a simple ownable geometric lowercase j/v monogram from one broad bent ribbon, subtly a descending hook followed by an ascending diagonal, with one precise negative-space cut. Flat vector-like silhouette only, near-black #20221E on a solid warm off-white #F5F5EE background. No text, no wordmark. One centered logo, large, generous padding, square 1024x1024 composition. Strong asymmetric balance, crisp edges, readable at tiny size. Do not resemble Vercel's triangle, Vue's V, Nike's swoosh, or any famous brand. No sparkles, lightning bolts, robot, gradients, 3D, mockup, shadow, texture, grid or surrounding decoration. This is a final brand mark for a website, not a sheet of concepts.
