## Observed checks

- The automated suite passed locally: 95 tests, 94 passed and the Windows-specific test skipped on macOS. Profile tests exercise actual CLI/library transitions, including user pins, agent selection, explicit clearing, invalid role composition, rejected privilege fields, task history, terminal/expired runs and preservation of the original scope, mode, authorization and budgets.
- Package tests execute profile discovery and pinned workflow creation from the extracted archive without relying on the source checkout. Every profile catalog, guide and canonical workflow link is included in packaging/validation.
- Native Codex and Claude installation lifecycles passed in isolated configuration directories. Their caches exposed 215 skills and the runnable v0.5.0 payload. This checks installation/discovery, not a native agent's adoption of a role.
- npm, pnpm 10, pnpm 12 and Yarn archive execution passed with 215 skills and 112 profiles. The persistent installed copy continued running after deletion of its temporary package source.
- Shared execution guidance and Git/GitHub contracts now explicitly prohibit agent self-attribution in commits, PRs and messages. The instruction review covers user ownership, configured Git identity, templates/hooks and preservation of human credits and required third-party notices.

## Limits

No new model-behavior success rate is claimed for the 112 roles. Profile schema/generation and runtime state are tested; profession-specific judgment still depends on the actual task, host, evidence and model. Existing catalog behavioral labels continue to refer to the exact [v0.4 fixture record](0.4.0.md), not to new role trials or a claim that the ownership instruction defeats every host's automatic footer.

Profiles are task context, not a sandbox or proof of user authorization. They do not automatically persist across new tasks or alter global host settings. The agent must ground a `selectedBy: user` entry in the actual user request. Host tooling can append text after a draft is prepared; the ownership guidance requires inspecting the resulting artifact and reporting a conflict rather than bypassing hooks or rewriting published history.
