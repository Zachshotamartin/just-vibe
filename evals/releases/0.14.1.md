# v0.14.1 validation

This patch release fixes updates of Claude Code installations made by 0.12.0 or earlier. In 0.14.0, `update --target claude` and `doctor --target claude` read the installed catalog with the workflow contract rules added in 0.13.0. The 0.12.0 `compare` workflow does not meet one of those rules, so both commands stopped with "Command compare: procedure[5] promises a write" before anything was replaced. Codex installations were not affected.

An installed catalog was validated by the release that built it. It is now read with shape checks only: schema version, unique well-formed command IDs, summaries and skill paths, which name the shortcut files written into the Claude configuration. The bundled catalog is still fully validated.

## Checks

- A new regression test stages a bundle, rewrites its `compare` entry as 0.12.0 shipped it, and confirms that shortcut doctor, the update preflight and uninstall work, and that a malformed command ID is still rejected. It failed with the reported error before the fix.
- In an isolated `JUST_VIBE_HOME` and `CLAUDE_CONFIG_DIR`, a real just-vibe 0.12.0 Claude installation could not be updated by the published 0.14.0 (same error). Updating it from the fixed source took the plugin from 0.12.0 to 0.14.0, kept its full selection of 221 skills, and `doctor --target claude` reported it healthy.
- Against the maintainer's real 0.12.0 Claude installation, the fixed `doctor --target claude` reports that the shortcuts need an update instead of failing.

Release preparation, CI and registry results belong in the publication record after they are observed.
