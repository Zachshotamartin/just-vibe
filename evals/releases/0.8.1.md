# v0.8.1 release validation

This patch release contains the reviewed runtime fixes and prompt improvements: cleanup approval identity, structured evidence redaction, permission-preserving writes/undo, symlink coverage, asynchronous browser assertions, retired-rule movement, request variants, input policies, worked examples and concrete profile contributions. See the [changelog](../../CHANGELOG.md) and [prompt development evidence](prompt-improvements.md).

Before version preparation, the source passed 176 tests (175 passed, one Windows-only skip on macOS), catalog/generation validation for 216 skills, skill-creator validation for all skills and npm package dry-run checks. The runtime repair also passed real Chromium checks, including delayed text, URL, title and focus assertions. Those are bounded checks, not universal platform or prompt-quality claims.

The release preparation reruns local checks, binds the archive to the clean source commit, exercises that exact archive through npm, pnpm 10/12 and Yarn 4, and records its SHA-256. Registry publication must match those bytes and execute the exact published version from an isolated directory/cache.
