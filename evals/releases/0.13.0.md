# v0.13.0 validation

The release applies the 278 findings of the September 2026 full review of commands, profiles, runtime, generator and documentation, and removes the default wall-clock limit on tracked runs. The catalog contains 221 skill names, 218 canonical workflows and 113 profiles.

## Routing

On 1,183 realistic requests from the review, the expected workflow ranks first for 63% of requests (0.12.0: 35%) and in the top three for 82% (0.12.0: 53%). The share missing from the top twelve fell from 27% to 9%. Both measurements use the same corpus and a neutral project root. On the catalog's own examples the expected workflow ranks first for 75% and in the top three for 91%. The test suite enforces these rates as a ratchet.

## Regression and packaging

`npm run release:check` passed at the release commit: validation, 500 tests with 497 passed and 3 platform-specific skips, and the archive check (650 files). The website built 359 pages and its 5 tests passed. On pull request #11, GitHub Actions passed on Ubuntu, macOS and Windows with Node 22 and 24, plus the web acceptance check. Two Windows jobs failed once on the final commit, from a test timeout and a temporary-folder lock during cleanup, and passed on rerun with no code change.

The publication procedure reruns release checks and tests the exact archive through npm, pnpm and Yarn before upload. Registry integrity, source commit, hashes and the results of that procedure belong in the separate publication record after they are observed.

## Limits

No live host or model trials were run for this release. The rewritten workflow text was verified structurally and against routing fixtures, not by observing agents follow it. The 0.12.0 publication record was reconstructed from registry metadata after the fact.
