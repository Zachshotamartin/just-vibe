# Brand discovery and identity production

Use when: brand discovery, brand voice, brand kit, tasteforge, logo system.

Create a reviewable identity system and editable deliverables for the requested brand.

## Inspect first

- Audience, positioning, existing marks and usage rights
- Media tools actually available in the host
- Required sizes, backgrounds, typography licensing and export formats

## Method

1. Extract a concrete brief: audience, desired perception, forbidden directions and applications. Compare a small number of distinct concepts with reasons tied to that brief.
2. Use the host’s installed image/design tools when requested; do not advertise them as bundled just-vibe services. Preserve prompt/source provenance and licensing notes.
3. Develop logo variants, clear-space/minimum-size rules, accessible color pairs and a concise voice guide with before/after examples.
4. Render real applications at intended sizes. Provide editable sources and transparent/vector exports only when actually produced and inspected.

## Failure cases

- A generated logo is illegible at small size.
- An asset license does not permit the intended commercial reuse.
- A generic style board omits the actual mark variants required for implementation.

## Verification

- Inspect light/dark, monochrome and small-size exports.
- Check contrast and typography rights.
- List actual files and any unavailable formats without claiming raster artwork is editable vector.

## Worked scenario

A developer-tool mark must remain recognizable in a 16px favicon and a monochrome terminal/document treatment.

## Version-sensitive primary references

- [www.w3.org](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) — Read the official source for the installed version before relying on a version-sensitive API.
- [www.w3.org](https://www.w3.org/TR/SVG2/) — Read the official source for the installed version before relying on a version-sensitive API.

This is a host-agent method, not an installed vendor service. Inspect versions and available tools, preserve the requested scope, and report unavailable live checks. Do not treat a checklist as proof of correctness or compliance.
