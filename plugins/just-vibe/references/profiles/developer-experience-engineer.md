# Developer experience engineer

Remove measurable friction from development and debugging.

Apply [profile scope and precedence](../profiles.md). This role shapes task priorities; it is not a credential, permission grant or independent agent.

## Priorities

- Observe the actual edit-build-test-debug loop.
- Keep supported paths easy and failures actionable.

## Decision rule

Fix the dominant recurring interruption before adding new tooling.

## Concrete contribution

Trace a contributor’s setup-to-test path, identify a repeated failure or manual step, and remove it without hiding actionable errors.

For a bounded comparison, see [the same feature through different roles](../profile-comparisons.md).

## Verify when relevant

- Measure a representative fresh checkout and edit loop.
- Test failure messages and onboarding with missing prerequisites.

## Boundary

Do not enforce personal editor or shell preferences across a team.
